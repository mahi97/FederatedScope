# LLM Wall-Clock Timing Run Order

## Overview

Measure server and client wall-clock overhead for each FL method on
Qwen 2.5 3B-Instruct / GSM8K. Runs 5 FL rounds with 10 local steps each.
Evaluation is disabled to avoid contaminating timing measurements.

## Quick start (single GPU)

Run all methods and scenarios sequentially on one GPU:

```bash
python scripts/run_llm_wallclock_matrix.py --gpu 0 --show-logs
```

## Parallel across GPUs

Run shared_b on one GPU and personalized_b on another:

```bash
python scripts/run_llm_wallclock_matrix.py --gpu 0 --scenarios shared_b --show-logs &
python scripts/run_llm_wallclock_matrix.py --gpu 1 --scenarios personalized_b --show-logs &
wait
```

Or split by method:

```bash
python scripts/run_llm_wallclock_matrix.py --gpu 0 --methods factor_fedavg,factor_fedprox,fa_lora --show-logs &
python scripts/run_llm_wallclock_matrix.py --gpu 1 --methods svd,svd_no_gram,fedma,full_rank --show-logs &
wait
```

## Generate the report

After all runs complete:

```bash
python scripts/build_llm_wallclock_rebuttal.py
```

This reads `RESULTS.md` (auto-generated by the matrix runner) and writes
`WALLCLOCK_REPORT.md` in this directory.

## Method matrix

| Method | Trainer | shared_b | personalized_b |
|---|---|---|---|
| factor_fedavg | llmtrainer | yes | yes |
| factor_fedprox | llmtrainer | yes | yes |
| fa_lora | llmtrainer | yes | **no** (requires shared lora_B) |
| svd (PERSIA) | llmsvdtrainer | yes | yes |
| svd_no_gram | llmsvdtrainer | yes | yes |
| fedma | llmsvdtrainer | yes | yes |
| full_rank | llmsvdtrainer | yes | **no** (requires shared lora_B) |

## Config differences from main rebuttal configs

- `total_round_num: 5` (was 200)
- `local_update_steps: 10` (was 50)
- `eval.freq: 1000000` (effectively disabled)
- `wandb.use: False`
- `federate.save_freq: 0`
- `federate.make_global_eval: False`
- `eval.llm.use_generation: False`

## Output files

- `RESULTS.md` — raw timing table (auto-appended by matrix runner)
- `WALLCLOCK_REPORT.md` — formatted rebuttal report (generated by builder)
